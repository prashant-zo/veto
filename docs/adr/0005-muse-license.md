# 0005 muse model license

status: accepted

Muse Spark Open is under the Muse Model License (Oct 15 2026).
What it means for us:
- show "Built with Muse Spark Open" in the readme and on the site
- veto code stays Apache-2.0, we never ship the weights ourselves
- the $20M model as a service rule does not touch us, veto uses the model as a part of its own product
- veto messages always say they come from veto, never pose as a person
- known limits of the ai go in the readme
- a model trained on its outputs would carry the same license and attribution
