# Veto brand

The mark is the signal lamp from Veto's track, lit red.

Veto shows every decision as a lamp on a track: green promotes, amber holds, red aborts. The mark is that
lamp at red, because stopping a release that does something its pull request never said is the job. The same
lamp is the UI favicon, the replay page track and the demo video.

| file | use |
|---|---|
| mark.svg | the mark alone, same as `src/veto/serve/static/icon.svg` |
| lockup-light.svg | mark and name, on light backgrounds |
| lockup-dark.svg | mark and name, on dark backgrounds |
| mark-512.png | 512 x 512, avatars and forms |
| social-preview.png | 1280 x 640, GitHub social preview and link cards |

Colors come from the Veto page: tile `#18222d`, ring `#e4e8e1`, lamp `#c2361e`. The name is Overpass
ExtraBold, turned into outlines so it looks the same everywhere. The lamp stays flat: no glow, no gradient,
no second color.
